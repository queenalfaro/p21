# Event App

> **Одно касание — и человек в зале с вами. Один дашборд — и вы видите этот зал насквозь.**

Event App — это PWA для проведения мероприятий любого масштаба: от внутреннего митапа на 10 человек до конференции на тысячи. Это единая централизованная **one-click** система связи между **участниками** и **организаторами**, построенная вокруг живой ленты в стиле Telegram — и усиленная тем, чего нет больше ни у кого: **эксклюзивной аналитикой вовлечённости аудитории в реальном времени**.

Никаких регистраций, паролей и установок из стора. Отсканировал QR → ввёл имя → ты уже в зале, общаешься со спикерами и видишь программу. А организатор в это время видит **пульс зала**: где стало скучно, а где — зацепило.

---

## Зачем это нужно

Любое мероприятие упирается в две стены:

1. **Со стороны участника** — высокий порог входа. Чтобы задать вопрос спикеру, нужно либо кричать в микрофон, либо ставить ещё одно приложение, либо искать ссылку на чат, регистрироваться, подтверждать почту... Большинство просто молчит. Энергия зала теряется.

2. **Со стороны организатора** — слепота. Доклад идёт, но **что чувствует зал прямо сейчас?** Сколько людей реально слушает, а сколько залипло в Telegram? Какой именно слайд всех зацепил, а на каком половина отвлеклась? Обратная связь приходит постфактум, в анкетах, которые заполняют единицы — когда менять что-либо уже поздно.

Event App убирает обе стены. Участнику — мгновенный вход и живое общение. Организатору — **объективную картину внимания зала в реальном времени**, секунда в секунду с тем, что происходит на сцене.

### Кому подходит

- 🏢 **Внутренние митапы и all-hands компаний** — быстрый Q&A, опросы, ощущение единого зала даже у распределённой команды.
- 🎤 **Конференции, форумы, meetup-сообщества** — сотни и тысячи участников в одной ленте без хаоса.
- 🎓 **Лекции, воркшопы, образовательные интенсивы** — спикер видит, в какой момент аудитория «поплыла», и подстраивается на лету.
- 📊 **Любое событие, где важна реакция зала** — презентации продуктов, демо-дни, питч-сессии.

## Что делает нас другими

На рынке есть либо «приложения для мероприятий» (Slido, Whova и подобные), либо просто Telegram-чат. Мы берём лучшее от обоих и добавляем то, чего нет ни у кого.

| | Telegram-чат | Типовые event-приложения | **Event App** |
|---|:---:|:---:|:---:|
| **One-click вход** (QR → имя → в зале) | ⚠️ нужен аккаунт | ❌ регистрация/установка | ✅ **за 5 секунд, анонимно** |
| Опросы, оценки, чеклисты в ленте | ❌ | ✅ | ✅ |
| Программа мероприятия (roadmap) | ❌ | ✅ | ✅ |
| **Аналитика вовлечённости в реальном времени** | ❌ | ❌ | ✅ **эксклюзивно** |
| **«Пульс зала»** — корреляция реакции с моментами | ❌ | ❌ | ✅ **эксклюзивно** |
| Установка как приложение (PWA, офлайн-оболочка) | — | ⚠️ через стор | ✅ прямо из браузера |

**Два наших главных козыря:**

### 🎯 Эксклюзивная аналитика аудитории

Насколько нам известно, **никто на рынке этого не даёт**. Мы измеряем не «сколько человек зашло», а **сколько человек реально вовлечено прямо сейчас** — и показываем это графиком, который дышит вместе с залом.

### ⚡ One-click доступ

Участнику не нужно ничего, кроме камеры телефона. Отсканировал код мероприятия → ввёл имя → готово. Ни почты, ни пароля, ни установки из стора. Самый низкий порог входа на рынке.

## 👥 Для участников

Всё, что нужно знать о мероприятии и сделать на нём — в одном экране, который ощущается как привычный мессенджер.

- **Вход за 5 секунд.** Сканируешь QR-код (или переходишь по ссылке, или вводишь код руками) → вводишь имя → ты в зале. Без регистрации, почты и паролей.
- **Живая лента в стиле Telegram.** Знакомые паттерны, знакомые кнопки — учиться нечему. Сообщения появляются в реальном времени.
- **Прямая связь со спикерами.** Задавай вопросы, обсуждай доклады, отвечай на реплики через привычные reply-цитаты.
- **Активности прямо в ленте.** Опросы, оценки докладов (⭐ 1–3), чеклисты — всё это специальные сообщения в общем потоке. Голосуешь в один тап, результаты обновляются вживую.
- **Программа мероприятия (roadmap).** Заранее видишь таймлайн: что и когда происходит, где ты сейчас на этой шкале.
- **Профиль на вырост.** Вошёл анонимно по имени — а захотел, апгрейднулся до полного профиля с юзернеймом и аватаром. Без принуждения.
- **Это PWA.** Устанавливается на телефон как обычное приложение, работает офлайн-оболочкой, шлёт push-уведомления о новых сообщениях.

> Приватность участника под защитой: никакой почты, телефона или OAuth мы не собираем. Вход полностью анонимный по желанию.

## 🎛️ Для организаторов

Вы получаете не просто чат, а **командный центр мероприятия** с тем, чего нет у конкурентов, — рентгеном внимания зала.

### Управление залом

- **Своё мероприятие за минуту.** Создаёшь комнату, задаёшь название, описание, расписание, аватар — и делишься QR-кодом/ссылкой одним экраном Share.
- **Полный контроль.** Модерация участников, назначение ролей (Спикер, Модератор) и прав, управление статусом мероприятия (Подготовка → В эфире → Завершено).
- **Запуск кастомных активностей.** Создаёшь опросы, оценки и чеклисты прямо в ленту в нужный момент доклада.
- **Удобный splitscreen на десктопе.** Управление | Чат | Аналитика — три панели в одном окне, каждую можно развернуть на весь экран или свернуть. На телефоне — те же возможности отдельными экранами.

### 📊 Эксклюзивная аналитика — «Пульс зала»

Главная причина выбрать Event App. Дашборд организатора обновляется в реальном времени и показывает то, что раньше было невозможно измерить:

- **График онлайна.** Сколько человек физически в зале прямо сейчас, в динамике от старта мероприятия.
- **«Пульс зала» — индекс вовлечённости.** Доля **вовлечённых / отвлечённых / неизвестных** участников во времени. Когда момент скучный — кривая падает. Когда зацепило — растёт. Вы **видите интерес зала как кардиограмму**.
- **Корреляция реакции с действиями.** Точки запуска опросов и активностей подсвечены прямо на графике. Кликаешь на точку → видишь, **как именно аудитория отреагировала** на этот конкретный момент. Какой слайд оживил зал, а какой — усыпил.
- **Сводка по активностям.** Развёрнутые результаты по каждому опросу и оценке в реальном времени.

> **Как это работает технически:** статус каждого участника (вовлечён / отвлечён / неизвестно) определяет честный rule-based decision engine на основе ~12 сигналов устройства (видимость экрана, фокус, движение, частота кадров, Web Worker heartbeat и др.). Приоритет — на правдивость, а не на охват: лучше «неизвестно», чем ложное «вовлечён». Вся аналитика работает **скрыто и асинхронно** и **никогда не тормозит само приложение** — интерфейс участника всегда в приоритете над сбором статистики.

## 🛠️ Технологии

Современный, выверенный под задачу стек — без оверинжиниринга.

| Слой | Технологии |
|---|---|
| **Ядро** | React 19 · TypeScript (strict) · Vite |
| **Роутинг** | React Router v7 (declarative SPA) |
| **Стили / UI** | Tailwind v4 (CSS-first, OKLCH) · shadcn/ui · Radix |
| **Server State** | TanStack Query v5 + Supabase JS · Supabase Realtime |
| **UI State** | Zustand |
| **Формы** | React Hook Form + Zod |
| **Производительность** | react-virtuoso (виртуализация ленты) |
| **Графики** | Recharts (серверная агрегация бакетами) |
| **PWA** | vite-plugin-pwa + Workbox |
| **Backend** | Supabase (Postgres + Realtime + Edge Functions) |
| **Деплой** | Cloudflare Pages |

Архитектура — строгий **Feature-Sliced Design** (`app → processes → pages → widgets → features → entities → shared`) с автоматической проверкой границ слоёв через ESLint.

## 🚀 Запуск проекта (для разработчиков)

```bash
# 1. Установить зависимости (требуется pnpm)
pnpm install

# 2. Настроить окружение
cp .env.example .env
# заполнить переменные Supabase в .env

# 3. Запустить dev-сервер
pnpm dev

# Сборка прода
pnpm build

# Линт
pnpm lint
```

> Проект использует уже развёрнутый Supabase-проект (схема в [`docs/supabase.md`](docs/supabase.md)). Локального Supabase CLI нет — работа со схемой через web SQL Editor.
